## 一、项目背景

当前大量家庭仍在使用传统红外家电，这类设备功能完好，但普遍缺少联网能力和智能交互能力。若直接整体更换智能家电，成本较高，也会造成一定资源浪费。

因此，本项目希望通过低成本外接硬件和 AI 决策能力，为传统家电补充“理解用户需求、生成控制建议、执行红外控制”的能力，让旧家电也能进入智能家居体系。

## 二、创新点

1. 不替换原有家电，通过红外桥接实现低成本智能化升级。
2. 引入大模型与规则结合的决策方式，支持自然语言控制与场景化建议。
3. 构建设备能力模型，对红外设备的动作范围和状态进行结构化管理。
4. 采用“AI 只建议、用户再确认、后端再执行”的机制，提升系统安全性和可解释性。
5. 将温湿度感知、网页控制台和本地 OLED 显示结合，形成完整原型系统。

## 三、技术方案

系统主要由四部分组成：

1. 前端控制台：用于展示设备状态、环境数据和接收用户自然语言输入。
2. 后端服务：负责 AI 决策、动作校验、设备状态维护以及调用 ESP32。
3. ESP32 硬件节点：负责接收后端指令、发射红外码并读取传感器数据。
4. 传感与显示模块：包括 DHT22 温湿度模块和 OLED 显示模块，用于本地状态反馈。

系统流程如下：

用户输入自然语言 -> 后端解析意图 -> 生成控制建议 -> 用户确认 -> ESP32 发射红外码 -> 家电执行 -> 系统更新状态

## 四、系统设计

当前系统已完成以下核心设计：

- 支持自然语言输入控制卧室空调开关。
- 支持 AI 决策与规则兜底双模式运行。
- 支持后端通过串口调用 ESP32 进行真实红外控制。
- 支持 DHT22 采集环境温湿度并同步到前端。
- 支持 OLED 显示 WiFi、服务状态、温湿度和空调状态。
- 支持维护设备推测状态、最后执行命令和状态可信度。

当前硬件清单如下：

| 硬件名称 | 说明 |
|---|---|
| ESP32-S3 开发板 | 作为系统主控与联网节点 |
| 红外发射模块 | 用于向传统家电发送红外控制信号 |
| 红外接收模块 | 用于学习和识别遥控器红外码 |
| DHT22 温湿度模块 | 用于采集环境温湿度 |
| 0.91 寸 OLED 显示屏 | 用于本地显示系统状态 |
| 面包板与杜邦线 | 用于原型搭建和模块连接 |

当前接线关系如下：

| 模块 | 接线方式 |
|---|---|
| DHT22 温湿度模块 | `DAT -> GPIO6`，`VCC -> 3V3`，`GND -> GND` |
| 红外接收模块 | `OUT -> GPIO5`，`VCC -> 3V3`，`GND -> GND` |
| 红外发射模块 | `DAT -> GPIO4`，`VCC -> 5V`，`GND -> GND` |
| OLED 显示屏 | `SCL -> GPIO18`，`SDA -> GPIO17`，`VCC -> 3V3`，`GND -> GND` |

## 五、实现过程

本项目的实现过程主要分为三个阶段。第一阶段完成软件原型搭建，建立前端控制台、后端接口与基础设备模型，实现自然语言输入、状态展示和动作建议。第二阶段接入 AI 决策能力，在保留规则兜底的前提下增加意图识别、动作校验和用户确认机制。第三阶段完成硬件联调，接入 ESP32、红外收发模块、DHT22 和 OLED 显示模块，打通真实红外控制链路，实现对传统家电的实际控制与状态反馈。

通过上述过程，项目已经从概念验证逐步推进到可演示、可交互、可联动的原型系统。

Smart Home AI 已完成从软件原型到硬件闭环的关键验证，证明了传统红外家电结合 AI 与嵌入式控制实现智能化升级的可行性。项目具有较好的展示效果、应用前景和进一步优化空间。
